# Knowledge Documents

Place the documents you want the chatbot to use as its
knowledge base in this folder.

The RAG pipeline processes these documents, generates
embeddings, and uses them for semantic and hybrid retrieval.

You can add your own company information, services,
products, FAQs, or other relevant documents here.

Example:

- company_information.txt
- services.txt
- products.txt
- faq.txt

The original company and persona documents are not included
in this public repository.
